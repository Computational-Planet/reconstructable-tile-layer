# Case Configs

English | [简体中文](README.zh-CN.md)

This directory is located at `case_configs/` in the repository root. It
contains JSON configurations for the cases demonstrated by the Reconstructable
Tile Layer demo. The subdirectories correspond to the individual cases.

## Usage

1. In **Experiment Import**, select **Custom / uploaded config**, click
   **Upload**, and choose a JSON file from this directory.
2. Click **Init Reconstruction Manager**.
3. Click **Load Tiles By Level** to render the configured case.
