# Third-party notices

[CesiumJS](https://github.com/CesiumGS/cesium), Apache-2.0, is supplied by the host
application as a peer dependency and is not bundled into this library.

`rtl-raster-source` supplies numeric raster decoding. See its notices for the
geotiff.js dependency and decoder licenses.

[TIFFImageryProvider](https://github.com/hongfaqiu/TIFFImageryProvider), MIT, informed
the integration evaluation. Its source is not copied or bundled. This adapter uses
the shared numeric source interface to keep scientific data and display styles
consistent, including bounded sampling of ordinary TIFFs without overviews.
