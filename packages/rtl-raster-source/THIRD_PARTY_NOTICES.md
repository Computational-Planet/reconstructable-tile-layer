# Third-party notices

This package depends on [geotiff.js](https://github.com/geotiffjs/geotiff.js), version
3.0.5, distributed under the MIT license. It is an npm dependency and is not copied
into the published source files. Its decoder dependencies retain their own licenses
and notices. Consumers bundling dependencies should retain those notices.

The project-owned small TIFF regression fixture is generated by
`test/generate-fixtures.py`. Public NOAA, PCMDI/IPSL and NCAR CCSM reference data are
downloaded separately for tests and are not included in this npm package.

The optional NetCDF worker bundles [netcdfjs](https://github.com/cheminfo/netcdfjs)
4.0.0 and iobuffer 6.0.1 (MIT). The NetCDF4 chunk bundles
[h5wasm](https://github.com/usnistgov/h5wasm) 0.10.3, developed by the National
Institute of Standards and Technology (NIST), and its embedded HDF5 library.
The complete upstream NIST/HDF5 license statement and MIT notices are included
in `licenses/`. The upstream libraries are bundled without source modifications;
the file-range reader, CF interpretation, worker protocol and lifecycle adapter
are project-owned code. Retain those notices when distributing worker assets.
